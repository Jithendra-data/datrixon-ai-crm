# Build versus buy

The calculator is an illustrative nominal three-year ownership model. Default licensing is 200 seats × $3,000 annually = $600,000. It is not a Salesforce quote, a verified replacement case or measured Datrixon saving.

Buy annual run rate = licenses + recurring integrations + internal support. Year 1 additionally includes SaaS implementation. Build annual run rate = infrastructure + AI usage + engineering maintenance + security + support. Year 1 additionally includes initial development and switching/migration.

Break-even years = (build initial − buy initial) / (buy annual − build annual), if annual savings are positive. A non-positive initial difference produces zero; an unfavorable annual difference yields no break-even. Uniform spending is assumed. Year 1, 2, 3 and totals are shown separately.

Missing factors include discount rate, inflation, growth, taxes, residual value, outage cost, feature gaps, technical debt, vendor dependency, integration complexity and engineering opportunity cost. Compare equivalent scope and service commitments. A spreadsheet result is not a procurement recommendation.

Customization and control can justify building even when costs are higher. Conversely, a capable vendor and limited internal engineering capacity can make buying the rational choice.
